Writing Guide

Elevate your thoughts with our custom-tuned Markdown system.

1. 投稿方式

如果你有想要分享的內容，歡迎將編寫好的 .md 文件發送至我們的官方郵箱：

Email: orly.sankuai@gmail.com

2. 基礎 Markdown 語法

本站支持標準 Markdown，並針對字體權重進行了優化。

加粗與斜體

**這是加粗文字**
*這是斜體文字*
這是加粗文字
這是斜體文字

3. 高級自定義組件

為了實現更牛逼的效果，你可以直接在文中嵌入以下 HTML 代碼。

A. 提示欄 (Tip Box)

<div class="tip-box">這是一個提示內容</div>
這是一個精緻的提示內容，帶有自動生成的感嘆號標誌。

B. 吐槽內容 (Spoiler)

<span class="spoiler">這是一段被蓋住的吐槽</span>
請鼠標懸浮查看：其實這是一段隱藏的數據塔密碼

C. 彩色流轉文字 (Rainbow)

<span class="rainbow-text">炫彩動態文字</span>
這段文字會不斷流轉顏色，充滿科技感。

D. 喵喵喵特效 (Meow)

<span class="meow-target">鼠標移過來</span>
試試看把鼠標移到這段文字上

E. 反向文字與刪除線斜體

<span class="reverse-text">反轉文字</span>
<span class="del-italic">刪除線斜體</span>
這是一段左右反轉的文字
這是一段帶有橫線且傾斜的過時筆記

F. 地理限制邊界 (Geofence)

在此標籤之後的內容將對中國大陸 IP 進行高斯模糊處理。

<div id="restricted-boundary"></div>

FAQ / 常見問題

Q: 為什麼我看不到文章內容，或者加載非常緩慢？

A: 由於我們的數據存儲與部分 API 服務（如 IP 地理位置檢查）部署在海外伺服器，如果您在中國大陸地區訪問，可能會遇到網絡阻斷或連接不穩定的情況。建議您使用 VPN 或代理工具後再次嘗試刷新頁面。

Q: 為什麼有些文字在鼠標移上去後消失了？

A: 那是因為作者使用了「喵喵喵」特效標籤。這是一個充滿童心的交互設計，文字會合體成一個「喵」字並拋出屏幕。

Q: 我可以提交繁體還是簡體文章？

A: 兩者皆可。我們的系統內置了 OpenCC 轉換引擎，用戶可以根據喜好隨時切換繁體與簡體，系統會自動處理文章的實時翻譯。
