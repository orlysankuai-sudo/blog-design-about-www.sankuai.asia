# 網絡連接障礙排除與代理部署指南 (步進式)


Author: Viel
#Coding

<div id="hidden-post"></div>

---

致讀者：如果您在訪問本站或全球互聯網資源時遇到加載緩慢、圖片無法顯示或連接超時，通常是因為您所處的網絡環境存在「邊界過濾」。本指南將從零開始，教您如何建立一個穩定的、加密的外部連接通道（俗稱：科學上網 / 代理）。

## 0. 核心概念理解（這很重要）

在開始動手前，您需要明白什麼是「代理（Proxy）」。
想像您的電腦要給遠在海外的朋友寄一封信，但郵局會檢查信封上的地址，發現是海外地址就直接銷毀。
**解決方案**：您先將信寄給國內的一個「中轉站（代理伺服器）」，這個中轉站會幫您把原信封套入一個普通的包裝裡，寄到海外的另一個中轉站，最後再由海外的中轉站交給您的朋友。



目前在中國大陸，傳統的 VPN（如 PPTP, L2TP）極易被識別並阻斷。目前主流且穩定的方案是基於**加密混淆協議**的代理，如 Shadowsocks (SS), V2Ray, Trojan 或 Hysteria。

---

## 1. 第一步：獲取「燃料」（訂閱鏈接）

代理軟體本身只是「車」，您需要「燃料」（伺服器節點）才能行駛。
在業界，提供這些伺服器的服務商通常被稱為「機場」。

### 如何選擇服務商？
1.  **避開「免費 VPN」**：免費通常意味著您的隱私數據被售賣，且速度極慢。
2.  **選擇專門的「機場」服務**：這類服務商通常提供 Shadowsocks 或 V2Ray 協議。
3.  **推薦標準**：優先選擇支持 **IEPL/IPLC 專線** 的服務商。這類線路不經過公網防火牆，延遲極低且極其穩定。

**具體操作：**
1.  在瀏覽器搜索或經由熟人推薦進入一個「機場」網站。
2.  註冊賬號並購買一個合適的套餐（通常按月或年付費）。
3.  在用戶後台尋找「**一鍵訂閱鏈接**」或「**複製訂閱地址**」。這串鏈接就是您的核心密鑰，請勿洩露。

---

## 2. 第二步：選擇並安裝「車輛」（代理客戶端）

根據您的設備系統，選擇對應的軟體。我們推薦目前最主流、功能最全的工具。

### A. Windows 用戶：推薦使用 `v2rayN` 或 `Clash Verge`
* **下載路徑**：前往 GitHub 釋出頁下載 `v2rayN-With-Core.zip`。
* **傻瓜式教學**：
    1.  解壓後執行 `v2rayN.exe`。
    2.  點擊頂部菜單的「訂閱」->「訂閱設置」。
    3.  在彈出窗口點擊「添加」，在「地址(url)」欄位黏貼您剛才從機場複製的訂閱鏈接，點擊確定。
    4.  回到主界面，點擊「訂閱」->「更新訂閱」。
    5.  底部任務欄右鍵點擊 v2rayN 圖標，「系統代理」選擇「**自動配置系統代理**」，「路由」選擇「**繞過大陸(Whitelist)**」。

### B. Android 用戶：推薦使用 `v2rayNG` 或 `Clash for Android`
* **傻瓜式教學**：
    1.  打開 App，點擊左側菜單，選擇「訂閱設置」。
    2.  點擊右上角「+」，黏貼訂閱鏈接並保存。
    3.  回到主頁，點擊右上角三個點，「更新訂閱」。
    4.  點擊右下角的「V」字圖標（連接按鈕）。當按鈕變色，即表示您已成功建立連接。

### C. iOS (iPhone/iPad) 用戶：唯一推薦 `Shadowrocket` (小火箭)
* **注意**：該軟體在中國大陸 App Store 已下架。您需要一個「外區（如美國、香港）Apple ID」。
* **傻瓜式教學**：
    1.  在 App Store 登入外區賬號並購買下載 `Shadowrocket`。
    2.  打開 App，點擊右上角「+」。
    3.  「類型」選擇 `Subscribe` (或掃描機場提供的二維碼)。
    4.  黏貼訂閱鏈接，點擊完成。
    5.  在主頁將「全局路由」設置為「配置」。
    6.  打開最上方的開關，允許添加 VPN 配置，指紋/密碼確認即可。

## 3. 第三步：正確的使用習慣（避坑指南）

很多新用戶在安裝後仍然無法上網，通常是因為以下原因：

### 1. 系統時間不對
**極其重要！** 代理協議（尤其是 V2Ray 和 Trojan）要求您的電腦/手機時間與網絡標準時間誤差不得超過 **90 秒**。如果時間不準，連接會立即失敗。
* **解決方法**：進入系統設置，開啟「自動設置時間」。

### 2. 全局模式 vs. 分流模式（配置模式）
* **分流模式（推薦）**：軟體會自動判斷。訪問百度、淘寶走國內直連；訪問 Google、YouTube 走代理。
* **全局模式**：所有流量都走代理。這會導致您訪問國內網站變慢，甚至被封鎖賬號。

### 3. DNS 洩漏與緩存
如果您發現開了代理依然上不去，請嘗試關閉瀏覽器並重新打開，或者在客戶端設置中點擊「清除 DNS 緩存」。

---

## 4. 故障排查清單

| 現象 | 可能原因 | 解決方案 |
| :--- | :--- | :--- |
| 連接後顯示 Timeout / 延遲 -1 | 訂閱鏈接失效或節點掛了 | 更新訂閱，或更換其他節點試試 |
| 瀏覽器提示「無法訪問互聯網」 | 系統代理沒打開 | 檢查客戶端是否開啟「自動配置系統代理」 |
| Telegram 能用但瀏覽器不能用 | 瀏覽器插件衝突 | 檢查是否安裝了 Proxy SwitchyOmega，將其改為「系統代理」模式 |
| 手機開了代理，電腦沒開 | 區域網共享未開啟 | 在手機客戶端開啟「允許來自區域網的連接」 |

---

## 5. 安全聲明與建議

1.  **隱私保護**：請勿在代理狀態下發表違反當地法律的極端政治言論。代理只是加密通道，並非絕對的「隱身衣」。
2.  **學術用途**：本指南僅供學習、開發與科研用途，旨在幫助開發者獲取最新的技術文件與開源代碼。
3.  **備份意識**：建議同時持有兩家不同服務商的「機場」訂閱，以防止單一服務商被突發性技術手段精確打擊。
